# TechBBQ Studio: downloads

Get the latest installer from the **Releases** page (right side of this page, "Latest").

- **Windows:** download `TechBBQ-Studio-Setup-<version>.exe` and double-click it. If Windows says "unknown publisher", press **More info**, then **Run anyway** (the app is not code-signed yet).
- **Mac:** download the `.dmg`, drag Studio to Applications. The first time, right-click the app and choose **Open**.

On first launch Studio opens a Setup page that installs what it needs. Sign in with your own Claude account.

Studio updates itself: when a new version is released you get a prompt in the title bar.

This repository only holds the installers. The source is private.
